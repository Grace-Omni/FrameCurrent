## Name

- Chinese: **连续影像**
- English: **FrameCurrent**
- Recommended first mention: **连续影像（FrameCurrent）**

“Frame” identifies moving-image creation; “Current” carries two useful meanings: the current frame being processed and a continuous visual current flowing through channels. The project claims the name and production marks as trademarks, but a formal clearance and registration review is still recommended before commercial launch.

## Mark

The green open loop represents continuity without claiming a perfect closed loop. The red forward triangle represents a live frame moving into the next one. The intentional opening is important: FrameCurrent reduces discontinuity but does not promise semantic perfection.

Production assets:

- `web/assets/logo-mark.svg` — compact mark and favicon.
- `web/assets/logo-lockup.svg` — Chinese/English lockup.
- `docs/brand/github-cover.svg` — repository cover.

Do not use `docs/brand/concepts/framecurrent-mark-v1.png` as the production logo; it is an image-generation exploration retained for provenance.

## Palette

| Token | Hex | Use |
|---|---|---|
| Current Lime | `#C8FF62` | continuity, active state, primary action |
| Signal Red | `#FF5D50` | play/live accent and warnings |
| Broadcast Black | `#080A09` | main background |
| Studio White | `#F3F6F0` | primary copy |
| Slate | `#919C94` | secondary copy |

Keep the mark flat. Do not add AI sparkles, robot heads, camera apertures, 3D bevels, or multicolor gradients.

## Voice

Prefer: calm, cinematic, concrete, transparent about limits.

Avoid: “perfectly seamless,” “truly live forever,” “zero drift,” or any claim that an image-boundary match proves coherent motion and story logic.
