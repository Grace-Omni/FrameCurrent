# 连续影像使用指南

[返回首页](../README.md) · 本指南适用于 macOS 本机版 1.6.2。

## 第一次启动

1. 从 [GitHub](https://github.com/Grace-Omni/framecurrent) 下载并完整解压源码。私有审核阶段需要仓库访问权限。
2. 双击 `doctor.command`。它会实际检查 Python、Swift、Apple 媒体工具、文件夹写入和三个媒体程序；不连接 fal，也不生成视频。
3. 若缺少工具，在终端运行 `xcode-select --install`，等安装完成后重新检查。首次安装/编译时间取决于你的环境。
4. 双击 `run.command`。网页地址为 `http://127.0.0.1:4173`，请保持启动终端开启。地址只在你的 Mac 上有效，不是分享链接。

不需要 npm、Node.js、Docker 或前端构建。Node.js 仅用于开发者测试。当前尚未验证 Windows / Linux / Intel Mac，不承诺兼容。

## 第一个30秒样片

选择预设频道，保留30秒、480P、10秒/幕。按需求选择横屏或竖屏。这里的30秒是成片长度，云端排队、逐幕生成和本地合并另需时间。

到 [fal 控制台](https://fal.ai/dashboard/keys) 创建 API Key 并确认账户有余额。不要把 Key 写入源码、Issue 或截图。把它输入网页，点击“连接并验证”；这一步只做账户查询，不提交生成任务，也不证明模型一定可用。

点击“开播这个频道”后，核对确认弹窗。根据软件内置参考费率，30秒 / 480P 的估算为 $1.50，不是 fal 最终账单保证。不接受费用就返回修改，取消不会提交生成。

确认后先检查本地媒体工具，再逐幕提交生成。缓存准备后自动预览；如果下一幕还未完成，播放器会等待。完成后先完整播放检查，再下载完整 MP4；末帧接上不保证人物、空间和动作始终合理。

## 换台、停止与取回片段

- 五个预设使用固定创作方向，每次生成的具体画面仍可能不同；频道图不是模型效果保证。
- 只有“自定义频道”显示节目设置。建议用一个主体、一个空间、一条持续运动路线。
- 换台不会提交任务，也不会停止原任务。当前一次只运行一个生成任务；别的频道运行时，上方提示可带你返回。
- 刷新网页会尝试找回当前运行频道；刷新本身不重新提交生成。
- “停止续写”阻止后续提交，但已提交的一幕仍可能计费，取消不是退款保证。
- 有已完成的片段时，“已保存片段”提供逐幕下载。固定时长中途停止或生成失败不保证自动合成完整 MP4。
- 退出前先在网页停止续写并等待保存，再关闭启动终端。关闭本机服务会尽力取消，并有限等待收尾；不能保证远端请求已取消。

## 故障排查

| 看到什么 | 下一步 |
|---|---|
| `.command` 不能直接打开 | 只对你信任的源码操作；在终端进入解压目录，运行 `chmod +x run.command doctor.command` 后执行 `./doctor.command`、`./run.command`。不要全局关闭 macOS 安全保护。 |
| 浏览器提示无法连接 | 重新运行 `run.command`，等待终端显示“已启动”；历史作品多时恢复检查较慢。保留终端开启，再在网页点击“重新连接”。 |
| 端口4173被占用 | 检查原启动终端是否仍运行。启动器仅复用同路径同版本的连续影像；不会关闭其他程序。旧版本正在生成时，先停播并保存，退出后再启动新版。 |
| 环境检查失败 | 完成 Apple 命令行工具安装；确认源码完整解压且文件夹可写；检查 macOS 是否允许终端访问该文件夹。不要通过再次付费来测试环境。 |
| 开播按钮是灰色 | 阅读按钮下的具体原因：本机连接、未验证 Key、另一个频道运行、时长无效或自定义内容缺失。 |
| 账户验证通过但生成失败 | 验证只证明账户查询可用；余额、模型权限和队列可用性仍以 fal 实际提交为准。先检查 fal 账户，不要连续重新开播。 |
| 开播请求超时、结果未知 | 保留当前浏览器数据、频道和源码目录。再次尝试会优先复用同一请求标识；不要换设备、清空浏览器数据后重复确认。 |
| 预览等待下一幕 | 模型生成速度不一定跟得上播放。查看进度和费用，不要因此重复开播。 |
| 画面衔接了但动作不合理 | 先下载样片检查；尝试5–10秒续写、减少角色与复杂动作。当前版本不能保证长片的语义与物理连续性。 |
| 作品处理/校验失败 | 先下载已保存片段，运行 `doctor.command`；生成已提交的部分可能已计费。不要把处理错误当成提示词问题反复生成。 |

## 保存位置与反馈

作品与首尾帧保存在源码目录的 `runtime/sessions/`，编译后的媒体工具在 `runtime/bin/`。它们不属于源码，不要放入 GitHub，也不要整目录上传给别人诊断。

普通问题可提交 [Issue](https://github.com/Grace-Omni/framecurrent/issues)，附软件版本、macOS版本、操作步骤与**脱敏**错误信息。不要附 Key、私人提示词、真实媒体、完整任务清单或包含这些内容的截图。安全漏洞请先读 [安全说明](../SECURITY.md)。
