# 连续影像使用指南

[返回首页](../README.md) · 本指南适用于 macOS 本机版 1.7.1。

## 第一次启动

1. 从 [GitHub](https://github.com/Grace-Omni/framecurrent) 下载并完整解压源码。私有审核阶段需要仓库访问权限。
2. 双击 `doctor.command`。它会实际检查 Python、Swift、Apple 媒体工具、文件夹写入和三个媒体程序；不连接 fal，也不生成视频。
3. 若缺少工具，在终端运行 `xcode-select --install`，等安装完成后重新检查。首次安装/编译时间取决于你的环境。
4. 双击 `run.command`。网页地址为 `http://127.0.0.1:4173`，请保持启动终端开启。地址只在你的 Mac 上有效，不是分享链接。

不需要 npm、Node.js、Docker 或前端构建。Node.js 仅用于开发者测试。Apple Silicon 与 Intel Mac 使用相同的启动流程，先用 `doctor.command` 检查本机依赖。Windows / Linux 用户可按下一节连接自己的 Mac 使用。

## Windows / Linux连接使用

连续影像在 Mac 端运行，Windows / Linux 作为浏览器操作端。准备一台你有权限使用的 Mac，两台设备应处于可互访的局域网或私人 VPN 中。

1. 在 Mac 上按“第一次启动”完成环境检查与启动，并保持 Mac 唤醒、启动终端开启。
2. 在 Mac 的“系统设置 → 通用 → 共享”开启“远程登录”，只允许自己的账户访问。完整步骤见 [Apple 远程登录指南](https://support.apple.com/guide/mac-help/allow-a-remote-computer-to-access-your-mac-mchlp1066/mac)。无需开启远程用户的完全磁盘访问权限。
3. 在 Windows Terminal（PowerShell）或 Linux 终端中运行下面的命令，将 `USER` 替换为 Mac 用户名、`MAC_ADDRESS` 替换为 Mac 的局域网或私人 VPN 地址。

```bash
ssh -N -o ExitOnForwardFailure=yes -L 127.0.0.1:4173:127.0.0.1:4173 USER@MAC_ADDRESS
```

首次连接时核对 Mac 的主机身份提示，再完成账户认证。登录后窗口保持等待是正常现象：`-N` 只建立连接，不进入远程命令行。保持该窗口开启，在当前电脑浏览器打开 `http://127.0.0.1:4173`。

- **Windows 找不到 ssh**：通过“可选功能”安装 OpenSSH 客户端，见 [Microsoft 安装指南](https://learn.microsoft.com/en-us/windows-server/administration/openssh/openssh_install_firstuse)。只需要客户端，不需要在 Windows 启动 SSH 服务端。
- **Linux 找不到 ssh**：通过发行版的软件包管理器安装 OpenSSH 客户端后再连接。
- **端口占用**：先退出客户端电脑上占用4173的程序；为保持应用的请求校验，转发两端使用相同端口。
- **连接失败**：检查 Mac 是否唤醒、远程登录是否为自己的账户开放，以及网络或 VPN 能否到达 Mac。不要把4173端口直接暴露到公网。
- **作品与任务**：作品原文件仍在 Mac，浏览器下载可以保存到当前电脑；切换设备前先在原浏览器停播并保存，避免重复开播。该方式供同一用户使用，不是多人共享服务。

结束时先在网页停播并保存，再按 `Control-C` 关闭 SSH 连接。关闭连接不会关闭 Mac 上的软件；在 Mac 的启动终端中退出应用。

## 第一个30秒样片

选择预设频道，保留30秒、480P、10秒/幕。按需求选择横屏或竖屏。这里的30秒是成片长度，云端排队、逐幕生成和本地合并另需时间。

到 [fal 控制台](https://fal.ai/dashboard/keys) 创建 API Key 并确认账户有余额。不要把 Key 写入源码、Issue 或截图。把它输入网页，点击“连接并验证”；这一步只做账户查询，不提交生成任务，也不证明模型一定可用。

点击“开播这个频道”后，核对确认弹窗。估算包含视频生成和 AI 剧情续写预留；30秒 / 480P / 10秒每幕当前为 $1.62，最终以 fal 账单为准。不接受费用就返回修改，取消不会提交生成。

确认后先检查本地媒体工具，再逐幕提交生成。缓存准备后自动预览；如果下一幕还未完成，播放器会等待。完成后先完整播放检查，再下载完整 MP4；末帧接上不保证人物、空间和动作始终合理。

## 换台、停止与取回片段

- 所有频道默认黑屏。点击“预览已生成视频”或“预览示例”才播放已有内容；“关闭预览”回到黑屏，不停止后台生成。新开播的节目在缓存就绪后仍会自动播放。
- 所有频道、所有时长都逐幕随机续写。频道定义视觉风格与世界，不预告具体事件；指定时长会引导当前故事在结尾收束。
- 只有“自定义频道”显示节目设置。描述主角、世界和喜欢的故事氛围即可。
- 换台不会提交任务，也不会停止原任务。当前一次只运行一个生成任务；别的频道运行时，上方提示可带你返回。
- 刷新网页会尝试找回当前运行频道；刷新本身不重新提交生成，也不自动播放历史画面。
- “停止续写”阻止后续提交，但已提交的一幕仍可能计费，取消不是退款保证。
- 有已完成的片段时，“已保存片段”提供逐幕下载。固定时长中途停止或生成失败不保证自动合成完整 MP4。
- 退出前先在网页停止续写并等待保存，再关闭启动终端。关闭本机服务会尽力取消，并有限等待收尾；不能保证远端请求已取消。

## 故障排查

### 剧情如何继续？

每幕先通过同一个 fal Key 调用 [OpenRouter Vision](https://fal.ai/models/openrouter/router/vision/api)，根据上一幕的首帧、中间帧、末帧和累计剧情记录，临时编写新的事件、因果与明显转折，再交给 H3 Max 生成视频。没有固定剧情表或循环分镜。有限时长和不限时长使用相同机制。

续写预留为每幕 $0.04（最多两次规划，每次 $0.02），这是本地估算余量，不是模型官方单价；有返回 `usage.cost` 时按该值更新支出，缺失或请求结果不确定时保留余量。重复或变化不足的候选最多重写一次，仍未通过会停止并保留片段。

图像样本和模型记忆不能证明整段视频的每个动作。重复检查包含模型语义自检、事件标记和文本相似度，并非绝对不重复的视觉保证。首次使用新续写方式，建议先生成短片检查结果。

本机 `runtime/sessions/<任务>/story-NNN.json` 保存每幕计划，`prompt-NNN.json` 保存视频提示词，`manifest.json` 中的 `_story_history` 保存计划和模型观察。它们不保存 API Key，也不会自动上传 GitHub。

| 看到什么 | 下一步 |
|---|---|
| `.command` 不能直接打开 | 只对你信任的源码操作；在终端进入解压目录，运行 `chmod +x run.command doctor.command` 后执行 `./doctor.command`、`./run.command`。不要全局关闭 macOS 安全保护。 |
| 浏览器提示无法连接 | 重新运行 `run.command`，等待终端显示“已启动”；历史作品多时恢复检查较慢。保留终端开启，再在网页点击“重新连接”。 |
| 端口4173被占用 | 检查原启动终端是否仍运行。启动器仅复用同路径同版本的连续影像；不会关闭其他程序。旧版本正在生成时，先停播并保存，退出后再启动新版。 |
| 环境检查失败 | 完成 Apple 命令行工具安装；确认源码完整解压且文件夹可写；检查 macOS 是否允许终端访问该文件夹。不要通过再次付费来测试环境。 |
| 开播按钮是灰色 | 阅读按钮下的具体原因：本机连接、未验证 Key、另一个频道运行、时长无效或自定义内容缺失。 |
| 账户验证通过但生成失败 | 验证只证明账户查询可用；余额、模型权限和队列可用性仍以 fal 实际提交为准。先检查 fal 账户，不要连续重新开播。 |
| 开播请求超时、结果未知 | 保留当前浏览器数据、频道和源码目录。再次尝试会优先复用同一请求标识；不要换设备、清空浏览器数据后重复确认。 |
| 预览等待下一幕 | 模型生成速度不一定跟得上播放。查看进度和费用，不要因此重复开播。 |
| 画面衔接了但动作不合理 | 先下载样片检查；尝试5–10秒续写、减少角色与复杂动作。当前版本不能保证长片的语义与物理连续性。 |
| 作品处理/校验失败 | 先下载已保存片段，运行 `doctor.command`；生成已提交的部分可能已计费。不要把处理错误当成提示词问题反复生成。 |

## 保存位置与反馈

作品与首尾帧保存在源码目录的 `runtime/sessions/`，编译后的媒体工具在 `runtime/bin/`。它们不属于源码，不要放入 GitHub，也不要整目录上传给别人诊断。

普通问题可提交 [Issue](https://github.com/Grace-Omni/framecurrent/issues)，附软件版本、macOS版本、操作步骤与**脱敏**错误信息。不要附 Key、私人提示词、真实媒体、完整任务清单或包含这些内容的截图。安全漏洞请先读 [安全说明](../SECURITY.md)。
